Requirements

  

    Needs the Web Serial API (Chrome or Edge 89+; Firefox and Safari will not work), and must be served rather
    than opened as a file — from the repository root run python3 -m http.server 8000 and open
    http://localhost:8000/tools/monitor/. Connecting here just opens the port for reading/writing; it does not
    reset the device the way the flasher's hard-reset does.
  

  

    Highlighting never hides a line — it only marks matches, so scrolling back (or the downloaded file) always has
    everything the device actually sent, not a filtered subset.
