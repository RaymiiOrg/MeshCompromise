    Requirements
    
  
    
    This uses the Web Serial API, so it needs Chrome or Edge 89 or later — Firefox and Safari will not work.
    It must be served rather than opened as a file. From the repository root run python3 -m http.server 8000 and open
    http://localhost:8000/tools/flasher/. If no port appears when connecting, hold G0 and tap reset to force download mode.
